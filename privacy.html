นโยบายความเป็นส่วนตัว

แอป History 2D · ปรับปรุงล่าสุด 24 พฤศจิกายน 2026

History 2D เป็นเครื่องมือส่วนตัวของเจ้าของช่อง History 2D ใช้ประกอบคลิปวิดีโอ และอัปโหลดขึ้นช่อง YouTube ของเจ้าของเอง ไม่ได้เปิดให้บุคคลทั่วไปใช้งาน

ข้อมูลที่แอปเข้าถึง

เมื่อผู้ใช้ให้สิทธิ์ผ่านหน้าจอยินยอมของ Google แอปจะได้รับสิทธิ์เดียวคือ

  • https://www.googleapis.com/auth/youtube.upload — สำหรับอัปโหลดไฟล์วิดีโอขึ้นช่องของผู้ใช้

แอปไม่ได้ขอและไม่ได้เข้าถึงอีเมล รายชื่อผู้ติดต่อ ไฟล์ใน Google Drive ข้อมูลผู้ชม สถิติของช่อง หรือข้อมูลส่วนบุคคลอื่นใดของผู้ใช้

ข้อมูลที่แอปเก็บ

แอปเก็บโทเคนสำหรับเข้าถึง YouTube API (refresh token) ไว้เป็นค่าลับของระบบ เพื่อให้อัปโหลดคลิปได้โดยไม่ต้องขอสิทธิ์ใหม่ทุกครั้ง โทเคนนี้ถูกเก็บในที่เก็บค่าลับ ที่เข้ารหัสของ GitHub Actions และในตัวแปรสภาพแวดล้อมบนเครื่องของเจ้าของเท่านั้น ไม่ถูกเขียนลงในซอร์สโค้ดหรือในบันทึกการทำงาน

นอกเหนือจากโทเคนดังกล่าว แอปไม่เก็บข้อมูลผู้ใช้อื่นใด ไม่มีฐานข้อมูลผู้ใช้ ไม่มีการเก็บประวัติการใช้งาน และไม่มีคุกกี้หรือระบบติดตามบนหน้าเว็บนี้

การเปิดเผยข้อมูล

แอปไม่ขาย ไม่แลกเปลี่ยน และไม่ส่งต่อข้อมูลที่ได้จาก Google ให้บุคคลที่สาม ข้อมูลถูกส่งไปยังปลายทางเดียวคือ YouTube Data API ของ Google เพื่ออัปโหลดคลิป

การใช้ข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนดเรื่องการใช้งานอย่างจำกัด (Limited Use)

การถอนสิทธิ์

ผู้ใช้ถอนสิทธิ์ที่ให้ไว้ได้ตลอดเวลาที่หน้า บัญชี Google · แอปของบุคคลที่สาม เมื่อถอนสิทธิ์แล้ว โทเคนที่เก็บไว้จะใช้ไม่ได้ทันทีและแอปจะอัปโหลดคลิปไม่ได้อีก

การติดต่อ

สอบถามเรื่องนโยบายนี้ได้ที่อีเมลสนับสนุนที่ระบุไว้บนหน้าจอขอสิทธิ์ของแอป ในหน้าจอยินยอมของ Google
